# ReplyMate Chrome Web Store Dashboard Notes

Use this file as the copy-and-paste source when filling in the Chrome Web Store dashboard.

## Single purpose

ReplyMate helps users draft customer-facing replies directly inside supported web apps such as
Slack, Gmail, and similar websites using either local models or the user's own AI provider API
credentials.

## Short description

Draft customer-facing replies in Slack, Gmail, and the web using local models or your own AI API.

## Permission justifications

### `sidePanel`

ReplyMate uses the Chrome Side Panel as the primary drafting surface alongside the active website.

### `activeTab`

ReplyMate uses `activeTab` to scope capture, refresh, and insertion actions to the page the user is
actively working in.

### `storage`

ReplyMate stores settings, encrypted vault metadata, and local workspace state in extension
storage. Raw provider keys are not stored unencrypted.

### `scripting`

ReplyMate injects the page bridge needed to capture context and insert drafts back into the active
composer on supported sites.

### Built-in host permissions

ReplyMate includes explicit host permissions for supported product surfaces and first-party provider
endpoints so that local-model and BYOK requests can run directly from the extension background.

### Optional host permissions

ReplyMate declares `https://*/*` under `optional_host_permissions` so Chrome can grant the exact
custom OpenAI-compatible provider origin only when the user explicitly configures one.

## Privacy disclosure notes

- Website content is accessed only to detect supported text boxes, capture visible nearby context,
  and insert the selected draft back into the active composer.
- Uploaded evidence files are processed locally in the extension when possible.
- Telemetry is optional and off by default.
- ReplyMate does not sell user data.
- ReplyMate does not proxy BYOK or local-model traffic through a ReplyMate-managed cloud service in
  the public store path.

## Launch assets

- Screenshots and promo images are generated by `npm run capture:store-assets --workspace @replymate/extension`
- Final files live in [`assets`](./assets/README.md)
- Store upload ZIPs are generated by `npm run package:store --workspace @replymate/extension`
