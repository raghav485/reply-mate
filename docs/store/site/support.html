ReplyMate Support

How to get help with ReplyMate.

ReplyMate support is currently handled through the public repository issue tracker and the store launch documentation.

Support channel

File an issue at github.com/raghav485/reply-mate/issues.

Before filing an issue

  • Include your Chrome version.
  • Include the ReplyMate version or commit if you are testing an unpacked build.
  • Specify whether you are using Local Models or Use Your Own API.
  • Include the provider kind, model name, and whether the vault is passkey-backed or passphrase-backed.
  • Share the exact error shown in Settings or the side panel.
  • Note whether the issue reproduces after reopening the side panel or restarting Chrome.

Common support topics

  • Vault relocking after Chrome unloads the background worker.
  • Custom provider host-permission prompts.
  • Ollama rejecting the Chrome extension origin.
  • Unsupported pages or missing focused composer detection.
  • Evidence parsing or image OCR capability mismatches.

Sensitive information

Do not include raw provider API keys, vault passphrases, passkey material, or unsanitized private customer content.

Privacy questions

Use the same issue tracker and clearly label the issue as a privacy question so it can be routed correctly.
