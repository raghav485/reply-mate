Store-facing pages ready for Chrome Web Store submission.

ReplyMate is a local-first Chrome extension that drafts customer-facing replies inside Slack, Gmail, and similar websites using local models or your own provider API key.

Privacy Policy Support

What ReplyMate does

ReplyMate captures the active draft plus nearby visible context from supported pages, then helps draft a response in the side panel without forcing you into a hosted AI subscription.

How provider access works

You can connect a local runtime such as Ollama or use your own OpenAI, Anthropic, Gemini, OpenRouter, or custom OpenAI-compatible endpoint directly from the extension.

Security model

Stored provider keys are encrypted before they are written to extension storage. Decrypted keys live only in the extension background while Chrome keeps it active.
