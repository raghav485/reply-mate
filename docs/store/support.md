# ReplyMate Support

## Support channel

ReplyMate support is currently handled through the repository issue tracker:

- Issues: <https://github.com/raghav485/reply-mate/issues>

## Before filing an issue

Please include:

- Chrome version
- ReplyMate version or commit/branch if testing an unpacked build
- whether you are using `Local Models` or `Use Your Own API`
- the provider kind and model name
- whether the vault is passkey-backed or passphrase-backed
- the exact error shown in Settings or the Side Panel
- whether the issue reproduces after reopening the side panel or restarting Chrome

## Common support topics

- vault relocking after Chrome unloads the background worker
- custom provider host permission prompts
- Ollama rejecting the Chrome extension origin
- unsupported pages or missing focused composer detection
- evidence parsing or image OCR capability mismatches

## Sensitive information

Do not include:

- raw provider API keys
- vault passphrases
- passkey material
- private customer content unless it is necessary and sanitized

## Privacy questions

Use the same issue tracker and clearly label the issue as a privacy question.
